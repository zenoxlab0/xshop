Place your payment QR code images here using the payment method key as the file name:

  upi.png        → shown on the UPI payment page
  bitcoin.png    → shown on the Bitcoin payment page
  crypto.png     → shown on the Crypto payment page
  <key>.png      → any method created with !setpayment

The easiest way to upload a QR code is the admin command:

  !setqr upi     (attach the image to the command message)

If no image exists for a method, the payment page simply shows the
payment address without a QR code.
